# 跨设备维护指南（Windows / macOS / Linux）

本指南用于解决以下场景：
- 你换了一台新电脑（例如 Mac）。
- 你已经从 GitHub 拉下项目。
- 你需要在新的 Codex 会话中无缝续写。

## 1. 新设备准备（以 macOS 为例）
执行前提：已安装 `git` 与 `python3`。

检查环境：
```bash
git --version
python3 --version
```

克隆项目：
```bash
git clone git@github.com:HoneyBury/novel.git
cd novel
```

切到主分支并同步最新：
```bash
git checkout main
git pull --ff-only origin main
```

## 2. 切换到新 Codex 会话后的第一步
在 Codex 新会话里，先让它读取并遵守项目规则。

建议第一条消息直接发：
```text
请先读取并严格遵守以下文件：
1) README.md
2) 05_prompts/long_term_constraints.md
3) 07_quality/chapter_exit_gate.md
4) 04_chapter_memory/canon_facts.md
5) 04_chapter_memory/rolling_memory.md
然后告诉我当前应从哪一章继续，并生成该章 context pack。
```

## 3. 继续写某一章的标准流程
以下流程建议每章重复一次。

1. 确认章节目标：
- 更新 `01_outline/beat_sheet.md` 的目标、冲突、钩子。

2. 生成最小上下文包（推荐 Python 统一三端）：
```bash
python3 08_tools/build_context_pack.py --chapter 12 --character-names 谢衡 苏明玥 小环 李飞
```

3. 投喂提示词并生成正文：
- 使用 `04_chapter_memory/context_pack_ch12.md`
- 搭配 `05_prompts/chapter_prompt_template.md`
- 强制执行 `05_prompts/long_term_constraints.md`

4. 写完后立即更新记忆层：
- `04_chapter_memory/chapter_12_summary.md`（若没有就新建）
- `04_chapter_memory/rolling_memory.md`
- `04_chapter_memory/timeline_ledger.md`
- `04_chapter_memory/character_state.md`
- `04_chapter_memory/open_questions.md`
- `04_chapter_memory/canon_facts.md`（仅新增，不覆盖旧事实）

5. 过闸门检查：
- 依据 `07_quality/chapter_exit_gate.md` 逐条检查。

## 4. 每 10 章一次的结构维护
当进入 10、20、30... 章节点时：
1. 更新/新增 `04_chapter_memory/arc_memory_arcXX.md`（500-800 字）。
2. 后续上下文优先喂：最近 2-3 章摘要 + 最新 arc memory。
3. 执行一次结构体检：节奏、因果、人物弧线、伏笔回收率。

## 5. Git 提交与推送（每次写作批次后）
查看改动：
```bash
git status --short
```

提交：
```bash
git add .
git commit -m "feat: chapter 12 draft and memory updates"
```

推送：
```bash
git push origin main
```

## 6. 发布可下载快照（可选）
打 `v.x.x` tag 后会自动发布 zip 快照到 GitHub Release。

```bash
git tag v1.2.0
git push origin v1.2.0
```

## 7. 常见问题
1. `python` 不存在：
- 在 macOS/Linux 使用 `python3`。

2. 新会话写崩人物：
- 让 Codex 先读取 `character_cards.md + relationships.md + canon_facts.md` 再继续写。

3. 上下文过长：
- 优先精简 `rolling_memory.md`，并使用 `arc_memory_arcXX.md` 替代旧章节全文。
