# 分卷与势力维护规范

## 1. 分卷原则
- 每卷 40-50 万字，建议约 100 章。
- 每卷必须具备三件套：
  - 卷文件：`01_outline/volumes/volume_XX_*.md`
  - 卷记忆：`04_chapter_memory/volume_memory/volume_XX_memory.md`
  - 卷首读者概览（写在卷文件中）

## 2. 卷首概览写法
- 必含一条引句（可诗句、可角色语录）。
- 必须明确“本卷主冲突”和“本卷承诺看点”。
- 不写设定堆砌，控制在读者可快速进入的密度。

## 3. 势力记忆维护
- 主账：`04_chapter_memory/faction_memory.md`。
- 归档：`99_archive/faction_archive.md`。
- 每章至少检查一次以下字段：
  - 关键职位是否变化
  - 当前状态是否变化（活跃/衰退/解散/已归档）
  - 当前卷相关度是否变化

## 4. 写作前检查单（最小）
1. 当前章 `beat_sheet` 目标明确。
2. 当前卷文件与卷记忆已更新。
3. 势力记忆已与上一章对齐。
4. 运行 `build_context_pack` 生成本章上下文。

## 5. 写作后回填单（最小）
1. 章节摘要 + rolling memory。
2. timeline + character state + canon。
3. faction memory + volume memory。
4. 必要时补 `open_questions` 与 `arc_memory`。
