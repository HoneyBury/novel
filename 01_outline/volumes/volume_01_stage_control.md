# 卷01阶段控制（作者补充）

## 阶段主轴
- 命案起势 -> 身份立足 -> 科举入场 -> 江南炼狱 -> 回朝受压与辞官。

## 章节分段（当前基线）
1. 1-7 章：命案与合作边界
- 目标：让苏明玥对谢衡“可用性”形成兴趣与验证。
- 重点：谢衡尚未真正意识到天下残酷，仍有“繁华错觉”。

2. 8-17 章：身份与科举（约 8-10 章）
- 目标：谢衡从“经商躺平”被现实与女主布局推向科举赛道。
- 重点：
  - 女主暗助谢衡拿到合法身份。
  - 谢衡察觉“有人帮他”，但暂不破局。
  - 科举过程完整表现：备考、场内博弈、士林排挤、殿试定名。
  - 谢衡在时代内合理使用 AI：提纲、校错、模拟问答、材料整理。

3. 18-37 章：江南任职（约 20 章）
- 目标：让谢衡看见“人间炼狱”，完成心境转折。
- 重点：
  - 民生/经济治理：粮、税、河运、盐价、疫病、治安联动。
  - 多势力斗争：地方官商、密云教余脉、青鸦会、异族渗线。
  - 林线推进：林龙参与，小环与林龙相认；林龙死于异族线冲突。
  - 女主幕后协同，与男主形成高质量配合。

4. 38-45 章：回朝与裂痕
- 目标：为下一阶段权力主战场埋钩。
- 重点：
  - 谢衡奉旨回朝后遭排挤，被林世藩针对。
  - 谢衡辞官，完成“制度内试修 -> 制度外破局”的转向。
  - 男女主因信任边界首次爆发实质矛盾，后续由小环线修复。

## 群像执行规范（卷01强制）
- 每 2-3 章至少一场群像。
- 群像必须可复用，禁止一次性工具人：
  - 李二牛：码头与运价视角
  - 王麻子：摊贩与粮菜价视角
  - 桂娘：药价与病势视角
- 群像必须回写主线：
  - “百姓处境变化 -> 主角决策变化 -> 政策/战术调整”三段链要可见。

## 本阶段禁止项
- 禁止科举一章速通。
- 禁止江南篇只写权谋不写民生。
- 禁止异族势力只报名字不落影响。
- 禁止男女主矛盾无因爆发或一章内强行和解。
