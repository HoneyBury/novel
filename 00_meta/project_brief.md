# 项目简报

## 基础信息
- 暂定书名：《烬火山河》
- 类型/子类型：历史架空 / 战争权谋 / 双穿越 / 慢热言情
- 目标读者：偏成人向（18+）历史剧情读者
- 预计总字数：180-240 万字
- 叙事视角（第一/第三/多视角）：多视角（以男主、女主双主视角为核心）
- 时态（过去/现在）：过去时

## 创作方向
- 核心主题：在乱世中以理性与仁心重建秩序；权力必须被规则约束。
- 情绪基调：前期压抑现实，中期高压博弈，后期恢宏温暖。
- 卖点（1-2 句）：高智军师女主 + 高情商执行型男主 + 本地 AI 辅助，在末代王朝废墟中从求生走向治世。
- 对标作品（可选）：晚明气质的架空战争群像 + 双强感情线。

## 硬约束
- 必须包含：
  - 男主穿越者身份；金手指为“可控核聚变供能的生物纹身终端 + 本地部署 AI + 全息投影”。
  - 女主高智商与超强记忆力在关键节点起决定作用。
  - 男主高情商与官场/军伍经验主导组织与执行。
  - 全文持续体现“女主智商高、男主情商高、AI 合理辅助”。
- 必须避免：
  - 无成本黑科技碾压；超越生产力的天马行空工业跳跃。
  - 男主后宫或女主多线感情；二人始终互为唯一伴侣并洁身自好。
  - 关键事件依靠巧合硬解。
- 内容分级上限：战争与权谋可写实，但不做露骨性描写与极端血腥细节堆砌。
- 语言风格限制：偏写实克制，避免现代网络口癖，关键术语保持时代感。

## 完成目标
- 目标章节数：320-420 章
- 章节平均字数：4000-6000 字
- 里程碑：
  - Arc-1（初遇与立志，1-60）
  - Arc-2（灭腐朽王朝，61-120）
  - Arc-3（攘外安内分歧与和解，121-180）
  - Arc-4（一统战争，181-240）
  - Arc-5（治国改革与成婚立嗣，241-300）
  - Arc-6（子嗣成长与扩展，301-360）
  - Arc-7（退位与圆满收束，361-终章）
