# 人物卡

## 男主：谢衡
- 身份定位：双主角之一；执行中枢；后期开国君主。
- 年龄/外在：26 岁（穿越时）；体能强，军伍训练痕迹明显。
- 前世背景：退伍军人，后任检察官，熟悉刑名法度、组织流程与官场人情。
- 金手指：
  - 生物科技纹身终端（可控核聚变供能，微型安全约束）。
  - 本地部署 AI（离线推演、资料索引、流程优化、战术复盘）。
  - 全息投影（演示地图、流程、草图、教学，不具备远程联网）。
- 表层目标：先求自保，后求立足，最终平乱治世。
- 深层需求：把“看见的不公”变成可复制的制度修复。
- 核心优势：高情商、强执行、跨阶层沟通能力、耐压。
- 核心短板：初期对乱世残酷性估计不足；易把责任过度揽在自己身上。
- 说话与行事：对上留余地、对下给台阶、对敌留后手。
- 压力状态：先稳队伍再解问题，极少情绪失控。
- 人物弧线：旁观者摆烂心态 -> 主动承担者 -> 制度建设者。

## 女主：苏明玥
- 身份定位：双主角之一；谋略中枢；后期开国皇后。
- 年龄/外在：15 岁（男主初到时，后续随剧情成年）；青楼花魁，卖艺不卖身。
- 穿越背景：5 岁穿越至此，早于谢衡十年，无系统型金手指。
- 天赋能力：超强记忆力 + 极高智商，擅长博弈、信息拼接、局势预判。
- 表层目标：在乱世自保并扩大可控筹码。
- 深层需求：让真正有能力者承担改变时代的责任。
- 核心优势：布局长线、识人精准、风险对冲意识极强。
- 核心短板：不易示弱，习惯独自承担，容易被误解为操控欲过强。
- 说话与行事：言简而锋利，擅长反问和留白。
- 压力状态：优先切割风险，必要时以身入局。
- 人物弧线：求存棋手 -> 共治军师 -> 与谢衡并肩的治世者。

- 类型：制度性反派。

- 功能：逼迫主角阵营处理“攘外/安内”战略选择。

- 类型：阶段性敌友转换体。
- 功能：制造合纵连横与信任博弈。
