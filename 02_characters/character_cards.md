# 人物卡

## 男主：谢衡
- 身份定位：双主角之一；执行中枢；后期开国君主。
- 年龄/外在：穿越前 36 岁；穿越后身体年龄 16 岁（年轻二十岁）；体能强，军伍训练痕迹明显。
- 前世背景：退伍军人，后任检察官，熟悉刑名法度、组织流程与官场人情。
- 金手指：
  - 生物科技纹身终端（可控核聚变供能，微型安全约束）。
  - 本地部署 AI（离线推演、资料索引、流程优化、战术复盘）。
  - 全息投影（演示地图、流程、草图、教学，不具备远程联网）。
- 表层目标：先求自保，后求立足，最终平乱治世。
- 深层需求：把“看见的不公”变成可复制的制度修复。
- 核心优势：高情商、强执行、跨阶层沟通能力、耐压。
- 核心短板：初期对乱世残酷性估计不足；易把责任过度揽在自己身上。
- 说话与行事：对上留余地、对下给台阶、对敌留后手。
- 压力状态：先稳队伍再解问题，极少情绪失控。
- 人物弧线：旁观者摆烂心态 -> 主动承担者 -> 制度建设者。

## 女主：苏明玥
- 身份定位：双主角之一；谋略中枢；后期开国皇后。
- 年龄/外在：15 岁（男主初到时，后续随剧情成年）；青楼花魁，卖艺不卖身。
- 穿越背景：5 岁穿越至此，早于谢衡十年，无系统型金手指。
- 天赋能力：超强记忆力 + 极高智商，擅长博弈、信息拼接、局势预判。
- 表层目标：在乱世自保并扩大可控筹码。
- 深层需求：让真正有能力者承担改变时代的责任。
- 核心优势：布局长线、识人精准、风险对冲意识极强。
- 核心短板：不易示弱，习惯独自承担，容易被误解为操控欲过强。
- 说话与行事：言简而锋利，擅长反问和留白。
- 压力状态：优先切割风险，必要时以身入局。
- 人物弧线：求存棋手 -> 共治军师 -> 与谢衡并肩的治世者。

## 女主贴身丫鬟：小环（原名林环儿）
- 身份定位：苏明玥贴身丫鬟；前中期为男女主沟通桥梁；感情催化角色。
- 出身背景：难民出身，被苏明玥救下带在身边，情同姐妹。
- 隐藏身世：当朝权相林世藩失散多年的私生女。
- 核心能力：能说会道、察言观色、擅长润滑冲突场景与民间联络。
- 剧情功能：
  - 前期作为“缓冲层”减少谢衡与苏明玥的误判与硬碰硬。
  - 中期因身份线牵引“林世藩阵营”立场变化。
  - 后期与李飞相识相恋，构成主角团稳定副线。
- 人物弧线：求生少女 -> 团队纽带 -> 认祖归宗后仍自选站队 -> 与李飞白头。

## 男主护卫：李飞
- 身份定位：谢衡贴身护卫；战争期核心将领；后期护国公爵。
- 出场前状态：经历黑暗事件后几近沉沦，后被谢衡救赎收编。
- 核心能力：天生力大无穷，近战压制力极强，战场执行效率高。
- 价值特征：忠诚、克制、不恋权位，擅长把复杂谋划转化为战场奇兵执行。
- 剧情功能：
  - 多次在生死节点保护双主角。
  - 战争阶段配合“谢衡执行 + 苏明玥谋划”完成破局。
  - 后期封公仍低调，持续作为主角手里的一把刀，参与微服私访。
- 感情线：与小环相识相恋，结局白头到老。

## 前期反派：林龙（密云教教主）
- 身份定位：Arc-1 至 Arc-2 关键反派与过渡型复杂角色。
- 家族背景：当朝权相林世藩之子；林环儿同父异母兄长。
- 行事方式：借“神迹/术法”欺骗百姓，实为物理化学知识包装与心理操控。
- 角色功能：
  - 作为苏明玥对谢衡的早期考验对象，测试男主识伪与行动力。
  - 最早识别林环儿身份，并对妹妹有强保护欲。
- 结局与评价：为护小环死于异族之手；功过相抵，遗信促成父女与阵营和解。

## 旧朝权相：林世藩
- 年龄：46 岁。
- 身份定位：前期制度性反派；后期悲剧性守国者。
- 人物特征：城府极深、手腕老辣、重家族与朝局平衡。
- 前期立场：因林龙之死且不明真相，与男女主强烈对立，并在第一次联手中败给二人。
- 关键转折：读到林龙遗信后解开误会，认出林环儿并让其认祖归宗。
- 终局选择：异族攻城时守卫皇城，自尽殉国；临终前交出关键势力给男女主以护小环。
- 角色评价：前期为敌、后期可敬，具传奇色彩的“能臣与父亲”双重形象。

## 关键外敌与对手群像
### 赫连达（北境异族统帅）
- 类型：外敌压力。
- 功能：逼迫主角阵营处理“攘外/安内”战略选择。

### 诸侯联盟（割据势力集合）
- 类型：阶段性敌友转换体。
- 功能：制造合纵连横与信任博弈。

## 感情硬约束
- 谢衡与苏明玥互为唯一伴侣。
- 全文无后宫、无替代性情感线、双方始终洁身自好。
- 恋爱关系确立应在双方心理与社会身份成熟后自然推进。
