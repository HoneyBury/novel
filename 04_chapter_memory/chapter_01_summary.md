# 第01章摘要

- 本章目标：建立谢衡穿越落地与初始求生路径，并引出“桥下命案+北仓账线”。
- 主冲突：谢衡原想低成本求生，却被命案与湿账纸逼到“不能只当路人”。
- 关键事件（3-5条）：
  - 谢衡确认穿越与离线终端可用，进入江宁府后快速完成环境扫描。
  - 谢衡在东市桥下命案现场以高情商稳住秩序，并提示捕快先取湿账纸角。
  - 神秘青轿在远处幕后观察，女主未直接露面，仅通过丫鬟转达警告。
  - 谢衡夜宿客栈梳理线索，获得孩童目击补证（桥东头推人）。
  - 谢衡夜赴北仓，听见“重写回执”关键对话。
- 结尾状态：谢衡由被动围观转为主动入局，决定以北仓线继续追查。
- 新增线索/伏笔：

  - 神秘青轿主人为何提前知情。
