# 第07章摘要

- 本章目标：完成桥下命案的可公证收束，做到“抓主使、回原账、闭证据链、可兑现交付”。
- 主冲突：冯七欲在废盐仓销账脱身 vs 谢衡需在混战中同步保住活口与账证。
- 关键事件（3-5条）：
  - 谢衡按“先抢火后拿人”组织三路设伏，李飞首次以实战协同身份参与卡井封口。
  - 废盐仓抓捕成功，冯七落网，两名护刀被擒，账箱与封口令未被烧毁。
  - 从书证中确认“周六既失口，桥下了账”命令，命案由意外争斗叙事转为有组织封口叙事。
  - 冯七供认周六命案执行链：周六发现北仓湿账异常 -> 试图携账出逃 -> 青鸦会下封口令 -> 冯七/老鸦执行。
  - 衙门公示命案结案与首批追缴返还，苦主获得可见结果，群像线与主线形成闭环回馈。
- 结尾状态：桥下命案主线完成阶段收束，但“郭掌柜/龙鳞签”仍在上层暗线；谢衡收到“暂籍协办不得越线”限制。
- 新增线索/伏笔：
  - “郭掌柜”作为冯七上级代号首次明确，仍未触及真实身份。
  - 中枢相关暗线对地方查案存在实质压制能力，后续需通过身份路径抬升权限。
- 必须延续的连续性事实：
  - 命案已收束的是“地方执行层”，非全网终局。
  - 相府与皇帝关注仍未进入正面剧情，只保留远端压力。
  - 男主维持“程序与协同优先”的办案风格。
