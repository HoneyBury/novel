# 第18章摘要

- 本章目标：在府试前夜封场拆封中阻断乙本名单渗透，并把争夺点前移到签位执行层。
- 主冲突：夜间执行口径被乙本渗透 vs 谢衡坚持封场逐条对照甲本。
- 关键事件（3-5条）：
  - 封场拆封启动三重门与第三见证，谢衡仅做甲本对照记录不越位干预。
  - 名单拆封中发现“联保另议”异动与同册异号页脚，谢衡当场启封场异议并固化取证。

  - 拆封后段再见“甲棚改乙棚”改笔，确认对手战术由名单渗透转向场务签位联动。
  - 入场唱签前夕，谢衡本人被发“乙号棚十九签”与甲本冲突，临门换签实锤落地。
- 结尾状态：名单层初步守住，但签位层正式开战；下一章进入入场门口即时反制。
- 新增线索/伏笔：
  - 乙本执行尝试不止名单权重，已延展到棚号与签位分配环节。
  - 场务房夜间木签流转与许澄偏厅活动形成时间重叠，疑似同链协同。
